# medical-app-streamlit
基于Streamlit的智能医学辅助系统，包含电子病历数据分析和肺部影像诊断演示。

 智能医学辅助系统

📖 项目简介

本项目是一个基于 **Streamlit** 构建的智能医学辅助系统演示平台，旨在展示：

- 智能医学的基本概念与应用场景
- 模拟电子病历数据的可视化分析
- 基于深度学习的肺部影像智能诊断演示（模拟）

> 该项目适用于医学与工科交叉课程教学、AI 医学应用入门演示。

---

🚀 功能模块

1. 课程与技术简介
- 介绍智能医学的定义、关键技术（计算机视觉、NLP、预测模型）
- 展示 AI 在医疗中的应用场景
- 包含图文并茂的界面布局

 2. 电子病历数据分析
- 模拟展示患者临床数据（年龄、血压、AI 评估风险等）
- 使用 Pandas 展示数据表格
- 可视化展示年龄与收缩压的关系

 3. 影像智能诊断体验
- 支持上传肺部 X 光或 CT 图像（JPG / PNG / JPEG）
- 模拟深度学习模型分析流程（含进度条与状态提示）
- 输出模拟的 AI 辅助诊断报告

---

 🛠 技术栈

- Python 3.7+
- Streamlit
- Pandas
- Pillow (PIL)

---

📦 安装与运行

1. 克隆项目

```bash
git clone https://github.com/your-username/medical-ai-system.git
cd medical-ai-system
```

2. 安装依赖

建议使用虚拟环境：

```bash
pip install streamlit pandas pillow
```

3. 运行应用

```bash
streamlit run medical_app.py
```

🧪 使用示例

1. 启动应用后，在侧边栏选择功能模块
2. 在“影像智能诊断体验”中上传一张医学图像
3. 点击“启动深度学习模型分析”观看模拟推理过程
4. 查看生成的辅助诊断报告
